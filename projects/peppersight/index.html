PepperSight

辣椒 AI 智能分级一体机

PROJECT TYPETEAM PROJECTSTATUSACTIVE
#Next.js#TypeScript#FastAPI#WebSocket#SQLite#YOLO11

MY ROLE负责 PepperSight 的前后端开发与现场联调，将团队的辣椒识别和分级能力落到可操作的质检系统中。后端用 FastAPI 组织检测、批次、记录与评级规则，前端用 Next.js + TypeScript 完成实时质检驾驶舱。

IMPLEMENTATION通过 WebSocket 同步检测结果和批次状态，完成实时质检、批次分析、检测记录与评级规则页面。链路从 USB 相机、OpenCV、YOLO11 和分级逻辑开始，由 FastAPI + SQLite 承载业务状态，最终在 Next.js 中实时展示。

CONTEXT / RESULT项目完成于首届贵客松，面向贵州干辣椒门店、合作社和中小加工场景。 现场完成了从真实辣椒、USB 摄像头到模型识别、等级判断和 Web 质检界面的完整 Demo。
